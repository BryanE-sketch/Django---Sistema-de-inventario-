# Sistema de Inventario - Django

Aplicación para controlar stock y movimientos de productos.

## Instalación local

1. Clonar el repositorio
2. Crear un entorno virtual e instalar dependencias: `pip install -r requirements.txt`
3. Copiar `.env.example` a `.env` y rellenar los valores
4. Ejecutar `python manage.py migrate`
5. Ejecutar `python manage.py runserver`
